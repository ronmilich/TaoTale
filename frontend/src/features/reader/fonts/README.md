# Noto Serif SC for the Reader

The bundled WOFF2 is the regular 400 instance of [Noto Serif SC](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notoserifsc), distributed under the [SIL Open Font License](../../../../public/assets/licenses/noto-serif-sc.txt). The source TTF has SHA-256 `050080d9255a86808f2945bffac582b31ef32bc36411ce29563b4961670c66f9`.

FontTools 4.69.1 subsets the font to GB 2312 level-one Han characters, ASCII and common punctuation (U+2000–206F, U+3000–303F and U+FF00–FFEE), then instantiates weight 400 and writes WOFF2 with Brotli 1.2.1. The CSS stack uses system fallback for other characters.
