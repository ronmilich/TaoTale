# 02 — TaoTale decision register

**Status:** Current TaoTale product and technology decision baseline — 23 November 2026.  
**Authority:** [`01-taotale-overview-and-features.md`](01-taotale-overview-and-features.md) governs product scope/MVP acceptance. [`03-taotale-client.md`](03-taotale-client.md), [`04-taotale-backend.md`](04-taotale-backend.md), [`05-taotale-database.md`](05-taotale-database.md) and [`08-taotale-design-system.md`](08-taotale-design-system.md) specify approved implementation boundaries. This register records those decisions and dispositions for **all D-01–D-61** legacy decisions (including D-25 a–u).  
**Not a completion claim:** `Active / MVP` means a target requirement, **not** evidence that code already implements it.

## 1. How to use this register

1. **Start with this document's `TT-` decisions.** Document 01 controls **product scope and MVP inclusion**; documents 03/04/05/08 control their respective technical specifications. If they conflict, reconcile the documents rather than treating an older technical choice as authoritative.
2. **Legacy `D-` entries are migration traceability**, not independent authority to reintroduce old behavior. Their original descriptions are recorded alongside the TaoTale treatment so implementation details are not lost.
3. **Status meanings:** `Retain` = existing behavior can remain; `Adapt` = carry forward with stated changes; `Supersede` = historical rule must be replaced; `Defer` = not an MVP requirement; `Review` = historical implementation detail still needs a choice; `Mixed` = the row contains both current and obsolete parts.
4. **Avoid assumption creep:** deferred work must not appear in MVP navigation, acceptance gates or mandatory services. It may be preserved as dormant reusable code if it has no visible dependency or operational burden.
5. New or changed consequential decisions get a new `TT-` ID. Do **not** renumber `D-` history; mark a decision superseded and link its replacement.

## 3. MVP implementation invariants and release gate

A developer can use these as quick non-negotiable checks. They are derived from document 01; detailed acceptance still lives there.

- **Persistence / network:** starting and restarting Docker PostgreSQL retains data; database and asset paths are persistent; **Go/Gin + pgx/v5/sqlc** access local PostgreSQL; UI/backend default to loopback; no signup/payment dependencies.
- **Language correctness:** `zh-CN` and `ko-KR` use distinct registered segmentation strategies; vocabulary, voices, source references and Library filtering observe the item's language; original source offsets remain stable.
- **Generation integrity:** audio is not READY merely because a provider returned bytes; verify duration and timing, persist exact fingerprint and strategy version, keep published assets immutable, handle unknown-billing outcomes safely.
- **Client/UI boundary:** **SolidJS** application imports the **standalone SolidJS-only npm UI package**, not `@kobalte/core` or Tailwind. Generic accessibility, overlays and component-level transitions live in the package; TaoTale owns Reader/audio and domain composition.
- **Primary workflows:** manually create/draft/generate/publish/read/download; edit metadata or revision; collect/manage vocabulary; assign Topics and difficulty; favorite draft/published item and filter them; configure Settings.
- **Cover limit:** 1,000,000 bytes is accepted (subject to other validations); 1,000,001 bytes is rejected on new/replacement upload. Preserve pre-existing larger files until reviewed.
- **Backup recovery:** a clean test can restore PostgreSQL metadata **and** referenced covers/MP3/timing/settings from a consistent backup.
- **Explicit exclusions:** no Dashboard, Vocabulary Practice, AI workspace, Islands Builder, phone-specific QA, auth or billing gate.

## 5. Migration and implementation change checklist

The old code may already implement many `D-` behaviors. This table is an **implementation migration checklist**, not an assertion of completed work.

| Area | Required change | Evidence / test |
|---|---|---|
| Naming & docs | Replace user-facing Mandarin Reader / Talezi names with TaoTale; keep migration identifiers stable. | UI navigation, package display strings and docs have no contradictory product name. |
| Runtime | Configure Docker Compose PostgreSQL with persistent volume, safe local credentials, health check and migrations; choose host/container deployment for backend. | Container recreate retains data; new volume bootstraps one User. |
| Backend rebuild | Replace NestJS/Prisma services with **Go + Gin + pgx/v5 + sqlc**, reviewed SQL queries and SQL migrations. | No ORM runtime; typed query generation and migrations pass on disposable local PostgreSQL. |
| Client rebuild | Implement **SolidJS + Vite + Solid Router**; preserve typed fetch/API, route guards, Reader performance and local preferences. | No React runtime; representative performance, navigation and API contract tests pass. |
| External UI package | Install the separately versioned **SolidJS-only npm UI library**; import generic controls from its public exports, apply Quiet Study via documented theming API. | `npm pack` consumer smoke; package CSS/types resolve; no app direct `@kobalte/core`, Tailwind or duplicated generic control implementations. |
| Local media | Define stable local asset root independent of container layers; safe paths/atomic writes; backup procedure. | Restart, file corruption, cleanup, disk-full and restore tests. |
| Ownership | Resolve one server-side default User; keep old owner IDs or migrate deterministically. Remove sign-in/account UI dependencies. | User data loads after startup without login; requests cannot pick arbitrary owners. |
| Language | Add `languageCode` to article/vocabulary/voice/defaults; migrate old content to `zh-CN`; add `ko-KR` and exclude mixed-language source links. | Cross-language duplicate words exist separately; foreign-language reference rejected. |
| Segmentation | Introduce per-language strategy registry/versions and golden source-offset/timing tests. Keep legacy Chinese assets pinned. | Chinese/Korean differ correctly; old recordings remain playable after strategy upgrade. |
| Audio identity | Extend new fingerprints with language + strategy ID/version without breaking legacy hash verification. Ensure Azure is behind adapter. | Invalid match cannot publish; an old published asset is not silently declared outdated. |
